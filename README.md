# 🍊 直到大地变成一颗酸橙 — 梗图生成器

本地运行的网页小工具:上传照片 → 自动把「直到XX变成一XXX」标题放到照片最合适的空白处 → 再叠上安洁莉娜动图/静态图/UI 贴纸 → 自由拖动、缩放 → 导出静态 PNG 或带动画的 GIF。

## 快速开始(三个入口)

| 方式 | 操作 | 适合 |
|---|---|---|
| 双击打开 | 双击 `index.html`(Chrome/Edge) | 自己用,零安装 |
| 本地链接 | 双击 `start.bat` → 自动打开 `http://127.0.0.1:8765/index.html` | 想要"链接"体验、或在 http 环境下用 |
| 公网链接 | 把 **`index-standalone.html`** 拖到 <https://app.netlify.com/drop>(免费) → 生成一个公网 URL,发给任何人都能点开直接用 | 分享给别人 |

> `index-standalone.html` 是单文件版:素材和代码全部内嵌(约 27MB),一个文件就能跑、能部署、能发人。

## 使用步骤

1. 点击「📷 上传照片」或直接把照片拖进画布区。
2. 程序自动分析照片、把标题文字放到较空旷的区域(可手动拖动调整)。
3. 左侧「安洁莉娜」面板:▶ 动图 / ▣ 静态,点击添加到画布;「UI 素材」添加贴纸。
4. 图层操作:拖动 = 移动;选中后滚轮 = 缩放(文字层调字号);双击 = 删除;「图层」面板可上移/下移。
5. 选中文字层可换颜色 / 描边 / 字号 / 样式预设(方舟白、柠檬黄、青柠…)。
6. 点「⬇ 导出 PNG」或「⬇ 导出 GIF(动图)」。

完全本地运行,图片不上传;断网可用(素材已内嵌)。

## 目录结构

```
LimeMemeStudio/
├─ index.html              主程序(多文件版,双击打开)
├─ index-standalone.html   单文件版(一个文件=全部,可部署/发人)
├─ start.bat               一键启动本地服务器并打开链接
├─ build.ps1               重新生成素材数据与单文件版
├─ assets-data.js          素材内嵌数据(由 build.ps1 生成)
├─ assets/
│  ├─ angelina/            10 组安洁莉娜 gif + png
│  ├─ ui/                  28 张 UI 贴纸
│  └─ vendor/              gif.js / gifuct.bundle.js(动图编解码)
└─ README.md
```

## 添加 / 替换素材

1. 把 `xxx.gif`(和同名 `xxx.png`)放进 `assets/angelina/`,UI 贴纸放进 `assets/ui/`。
2. 运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`(会重新生成 `assets-data.js` 和单文件版)。
3. 刷新页面即可。

## 常见问题

- **导出 GIF 一直"处理中"?** 已修复:现用主线程编码(`workers: 0`),不再依赖 Web Worker,`file://` 双击打开也能正常导出;同时加了错误提示与 60 秒超时保护。
- **导出太慢?** 大照片会自动限制到 2200px 内,减少图层/换小图会更快。
- **想自己做个字体样式?** 文字面板里可自定义颜色/描边/字号,或用预设一键切换。

## 自动找位置的原理

照片缩成 96×96 分析,分 8×8 块,计算每块亮度标准差(画面细节密度),在偏上方区域挑最"空"的块放标题。启发式算法,复杂照片下不完美——直接拖动文字即可。
